# Museum Video Catalog

Catalogo video statico realizzato con Astro. I contenuti sono gestiti in `src/data/videos.json`.

## Avvio locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Aggiungere un video

Aggiungi un oggetto in `src/data/videos.json`. Per YouTube usa l'URL embed:
`https://www.youtube.com/embed/VIDEO_ID`

Le immagini di copertina vanno in `public/images/`. I file video non vanno caricati su GitHub.
